# eixut

Dry in Catalan.

---

I think [Bleak Sword](https://en.wikipedia.org/wiki/Bleak_Sword)'s mobile controls are some of the best mobile controls ever in a game. The game also happens to be excellent (very recommended!).

I wondered how complex it would be to get Gemini to get a reasonable approximation of those controls, and here we can see that with some nudging (first commit was around a couple hours of prompting and tweaking), it can lead to something "playable".
